# MusicApp

MusicApp es un reproductor de música para Windows. Guarda tus canciones en tu ordenador, con su portada, y las escuchas cuando quieras, también sin conexión.

## Descargar

**[Descargar la última versión](https://github.com/llatzer-dev/music-app-releases/releases/latest)**

1. Entra en el enlace y descarga el archivo `MusicApp-Setup-….exe`.
2. Ábrelo y sigue los pasos.

No hace falta instalar nada más. La primera vez, Windows puede mostrar un aviso azul: pulsa «Más información» y luego «Ejecutar de todas formas».

## Qué puedes hacer

**Guardar música**

- Copia el enlace de una canción y pulsa «Pegar y descargar». La canción se guarda con su nombre, su artista y su portada.
- Funciona con enlaces de YouTube, Spotify y osu!, tanto de una canción suelta como de una lista entera.
- Mientras se descarga ves cuánto falta, y puedes cancelar o volver a intentarlo.

**Escuchar**

- Reproductor con todo lo habitual: pausa, siguiente, anterior, volumen, modo aleatorio y las teclas multimedia del teclado.
- Reproducción sin fin: cuando se acaban las canciones, vuelve a empezar.
- Una cola con lo que va a sonar después, que puedes reordenar arrastrando.

**Organizar**

- Una biblioteca con todas tus canciones, con buscador y varias formas de ordenarlas.
- Listas propias: créalas, ponles el nombre y la imagen que quieras y ordena sus canciones arrastrando.
- Cada canción muestra de dónde viene y en qué listas está. Pulsando esas etiquetas, o el nombre del artista, ves todas las canciones relacionadas.

**Ajustar a tu gusto**

- Corrige el título o el artista de una canción si no han salido bien.
- Elige qué parte de una canción suena, por ejemplo para saltarte una introducción larga.
- Guarda una lista en un archivo para tener una copia o pasársela a otra persona.

## Actualizaciones

Al abrir la app, se comprueba sola si hay una versión nueva. Si la hay, te pregunta antes de instalarla.

## Aviso

MusicApp es un proyecto personal. Descarga solo música que tengas derecho a guardar.
