# MusicApp · descargas

Instaladores de MusicApp para Windows (64 bits).

Descarga `MusicApp-Setup-<versión>.exe` desde la [última versión](https://github.com/llatzer-dev/music-app-releases/releases/latest) y ejecútalo. Lo trae todo: no hace falta instalar nada más.

El instalador no está firmado, así que Windows SmartScreen puede avisar la primera vez («Más información» → «Ejecutar de todas formas»).

La app comprueba al abrirse si hay una versión nueva y pregunta antes de actualizar.
